# 需求分析

## 1. 问题背景

多本教材在同一学科内存在大量重复知识点，教师和学生需要一个工具完成：

1. 多格式教材解析
2. 知识点抽取
3. 知识图谱可视化
4. 跨教材知识点去重与压缩
5. 基于来源可追溯的 RAG 问答
6. 教师反馈驱动的整合修正
7. 自动生成教学大纲

## 2. 知识点粒度定义

本项目将知识点定义为教材中具有独立教学意义的概念、定理、方法、现象或应用场景。

字段包括：

- `name`：知识点名称
- `definition`：教材内定义或解释
- `category`：核心概念 / 方法 / 定理 / 现象 / 应用
- `chapter`：所在章节
- `page`：页码
- `source_textbook`：来源教材
- `frequency`：出现频次（跨教材）

## 3. 重复判定标准

两个知识点满足以下条件之一时，可判定为候选重复：

1. **词标匹配**：名称完全相同或高度相似（包含关系）
2. **Embedding 相似度**：余弦相似度高于阈值（默认 0.78）
3. **LLM 判断**：语义等价

## 4. 压缩比计算方式

```text
压缩比 = 整合后知识库总字数 / 原始教材总字数
```

目标：不超过 30%。

## 5. RAG 分块策略

- **chunk_size**：约 700 中文字符
- **overlap**：约 120 中文字符
- **metadata**：教材名称、章节标题、起始页码

理由：500-800 字能兼顾语义完整性与检索精度，overlap 可以降低知识点跨 chunk 被截断的问题。

## 6. 混合检索设计

### 6.1 BM25 检索（精确匹配）

基于 TF-IDF 的词频统计算法，适合精确术语匹配。

```python
# 词标化
query_terms = jieba.lcut(query)

# 计算 BM25 分数
scores = tfidf_vectorizer.transform(query).dot(tfidf_matrix.T).toarray()
```

### 6.2 Embedding 检索（语义匹配）

基于 sentence-transformers 的语义向量检索，适合同义词、近义词匹配。

```python
# 编码
query_emb = model.encode(query)
chunk_embs = model.encode([chunk["text"] for chunk in chunks])

# 余弦相似度
similarities = cosine_similarity([query_emb], chunk_embs)
```

### 6.3 RRF 融合

Reciprocal Rank Fusion，将多个检索结果按排名融合：

```python
def rrf_fusion(results_list, k=60):
    scores = defaultdict(float)
    for results in results_list:
        for rank, item in enumerate(results):
            scores[item] += 1 / (k + rank + 1)
    return sorted(scores.items(), key=lambda x: x[1], reverse=True)
```

## 7. 整合决策类型

| 决策 | 说明 | 触发条件 |
|------|------|----------|
| `merge` | 多本教材共有，建议合并 | 2+ 本教材出现 |
| `keep` | 单本独有但信息量大 | 单本出现 + char_count > 1200 |
| `supplement` | 可能缺失 | 覆盖教材少 + 教师未标记 |
| `remove` | 重复过多，考虑删除 | 未使用 |

## 8. 教师反馈处理

### 8.1 保护信号词

```python
PROTECT_SIGNALS = {
    "保留", "不能删", "不能压缩", "考试", "重点",
    "实验", "案例", "前置", "基础", "核心", "必须掌握"
}
```

### 8.2 处理流程

1. 检测反馈文本中的保护信号词
2. 提取相关知识点
3. 标记为 `needs_teacher_review = True`
4. 整合报告中生成复核建议
