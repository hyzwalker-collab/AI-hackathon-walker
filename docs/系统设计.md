# 系统设计

## 1. 技术选型

| 层级 | 方案 |
|---|---|
| Web 框架 | Streamlit |
| PDF 解析 | PyMuPDF |
| 文本解析 | Python 原生读取 |
| 知识图谱 | NetworkX + pyvis |
| Embedding | sentence-transformers |
| 向量检索 | FAISS |
| LLM 调用 | OpenAI-compatible API |
| 数据存储 | JSON + session_state |
| 报告生成 | Markdown 模板 |

## 2. 数据流

```mermaid
graph TD
A[用户上传教材] --> B[文件解析模块]
B --> C[章节结构 JSON]
C --> D[知识点抽取模块]
D --> E[单本教材知识图谱]
E --> F[跨教材对齐模块]
F --> G[整合知识库]
G --> H[RAG 索引]
H --> I[带引用问答]
F --> J[整合报告]
```
