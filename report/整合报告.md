# 整合报告

## 1. 整合概览

当前项目骨架阶段尚未上传正式 7 本教材数据。

后续系统运行后将自动填充：

- 原始教材数量
- 原始总字数
- 整合后字数
- 压缩比

## 2. 整合决策摘要

待跨教材对齐模块完成后自动生成：

- merge 数量
- keep 数量
- remove 数量

## 3. 知识图谱统计

待知识图谱模块完成后自动生成：

- 整合前节点数
- 整合后节点数
- 关系数变化

## 4. 重点整合案例

待系统运行后自动选择 3-5 个典型案例。

## 5. 教学完整性说明

系统将通过前置依赖关系保留、章节覆盖率和教师反馈修正机制，尽量保证整合后教学逻辑链路不断裂。
